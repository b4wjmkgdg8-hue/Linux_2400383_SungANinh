## 2. Gioi thieu
Bai thuc hanh Linux Shell Script va quan ly ma nguon bang Git, GitHub.

## 3. Cau truc thu muc
- data/: Chua du lieu sinh vien.
- scripts/: Chua cac chuong trinh Shell Script.
- logs/: Luu nhat ky hoat dong.
- backup/: Luu cac file sao luu.
- README.md: Tai lieu huong dan.

## 4. Mo ta cac chuong trinh

### hethong.sh
Hien thi ten nguoi dung, ten may tinh, ngay gio, thong tin kernel, RAM, dung luong dia va kiem tra ket noi mang.

### quanlysv.sh
Quan ly danh sach sinh vien: hien thi, tim kiem, thong ke dat/khong dat, tinh diem trung binh, tim diem cao nhat va sap xep diem giam dan.

### saoluu.sh
Kiem tra thu muc data, nen du lieu bang tar, luu file vao backup va ghi nhat ky vao logs/backup.log.

## 5. Huong dan chay chuong trinh

Cap quyen thuc thi:

```bash
chmod +x scripts/*.sh
```

Chay chuong trinh kiem tra he thong:

```bash
./scripts/hethong.sh
```

Chay chuong trinh quan ly sinh vien:

```bash
./scripts/quanlysv.sh
```

Chay chuong trinh sao luu:

```bash
./scripts/saoluu.sh
```

## 6. Ket qua
Cac chuong trinh duoc thuc hien tren Ubuntu Linux (WSL), su dung Bash Shell Script.

Da kiem tra va hoan thien huong dan su dung cac chuong trinh.
